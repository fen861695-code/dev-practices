# 术语大白话词典（中英对照）

按类别收录开发中最常遇到的术语，每条都用生活语言解释。遇到没见过的词随时回来查。

## 一、基础概念

- **程序（Program）**：写给电脑、让它逐条照做的指令清单。
- **代码（Code）**：程序的具体文字内容。
- **编程语言（Programming Language）**：人和电脑沟通所用的语言，如 JavaScript。
- **前端（Frontend）**：用户在浏览器里直接看到、操作的部分（餐厅的大堂和菜单）。
- **后端（Backend）**：在服务器上处理逻辑、读写数据、用户看不到的部分（餐厅的厨房）。
- **全栈（Full-stack）**：前端和后端都涉及。

## 二、网页三件套

- **HTML**：决定网页"有什么"的结构语言（房子的墙、门、窗）。
- **CSS**：决定网页"长什么样"的样式语言（装修和软装）。
- **JavaScript（JS）**：决定网页"能做什么"的编程语言（水电和开关）。
- **DOM（文档对象模型）**：浏览器把网页整理成的一棵"家谱树"，JS 通过它读取和修改页面。
- **浏览器（Browser）**：请求网页并把 HTML/CSS/JS 渲染成画面的软件。

## 三、后端与网络

- **服务器（Server）**：一台 24 小时运行、等待请求并给出响应的电脑或程序（一直营业的店铺）。
- **接口 / API（应用编程接口）**：前后端约定好的"点单方式"，前端按它请求、后端按它处理。
- **HTTP**：浏览器和服务器之间沟通所遵循的一套规矩。
- **请求（Request）/ 响应（Response）**：前端发出的"点单"和后端端回的"菜"。
- **状态码（Status Code）**：用数字表示这次请求的结果，如 200 成功、404 没找到、500 服务器出错。
- **JSON**：一种轻量、易读的数据格式，前后端常用它传递数据，长得像 `{ "text": "买牛奶", "done": false }`。
- **中间件（Middleware）**：请求到达处理逻辑前先经过的一道道关卡（如解析 JSON、记录日志）。
- **localhost**：永远指"本机"的特殊地址。
- **端口（Port）**：服务器上的门牌号，如 3000。
- **CORS（跨域资源共享）**：浏览器对"页面和接口不同源"时的安全限制；同源（同一地址）则不受限。

## 四、数据

- **数据库（Database）**：专门长期存放、管理数据的软件（厨房的仓库）。
- **SQLite**：最轻巧的数据库，整个数据库就是项目里的一个文件，无需单独安装。
- **SQL（结构化查询语言）**：和数据库对话的语言，用于建表、增删改查。
- **表（Table）/ 字段（Field）/ 记录（Record）**：数据的"表格 / 列 / 一行行内容"。
- **主键（Primary Key）**：能唯一标识一条记录的字段，通常是 id。
- **CRUD**：数据的四种基本操作——增 Create、查 Read、改 Update、删 Delete。
- **SQL 注入（SQL Injection）**：攻击者通过输入恶意内容篡改 SQL 的攻击手段；用占位符 `?` 传参即可防范。

## 五、工程与协作

- **Git**：在本地记录代码所有版本的"存档系统"。
- **GitHub**：存放和协作管理代码的"云盘 + 平台"。
- **仓库（Repository, Repo）**：被 Git 管理的一个项目文件夹。
- **提交（Commit）**：一次存档，给当前代码拍快照并附说明。
- **暂存区（Stage）**：提交前的取景框，决定哪些改动进入本次存档。
- **分支（Branch）**：从主线复制出的平行草稿，可在上面独立修改。
- **推送（Push）/ 拉取（Pull）**：把本地提交上传 / 把远程最新版本下载。
- **Pull Request（PR，拉取请求）**：请求把某分支的改动合并到主线，并在此进行评审。
- **合并（Merge）**：把一个分支的改动并入另一个分支。
- **代码评审（Code Review）**：他人阅读代码、提出意见后再合并的质量把关。

## 六、环境与工具

- **终端 / 命令行（Terminal / CLI）**：用打字向电脑下命令的地方。
- **Node.js**：让 JavaScript 能在浏览器之外（服务器、本机）运行的环境。
- **npm**：Node.js 自带的包管理器，用来下载、管理别人做好的工具（"软件商店管家"）。
- **依赖 / 库 / 包（Dependency / Library / Package）**：别人写好、可借来用的现成工具。
- **node_modules/**：存放已下载依赖的文件夹，体积大、不提交、可重新安装。
- **环境变量（Environment Variable）**：在运行环境中配置的值（如端口、密钥），代码用 `process.env` 读取。
- **构建 / 编译（Build / Compile）**：把源代码处理成可运行或可发布产物的过程。
- **调试（Debug）**：定位并修复程序问题的过程。
- **Bug**：程序中的缺陷或错误。
- **部署（Deploy）**：把项目放到服务器上对外运行。
- **域名（Domain）**：网站的文字地址，背后指向某台服务器。
- **托管平台（Hosting Platform）**：提供服务器、帮你运行项目的云服务。

## 七、测试

- **测试（Test）**：自动检查代码是否正确的代码。
- **单元测试（Unit Test）**：验证单个函数在各种输入下输出正确。
- **集成测试（Integration Test）**：验证多个部分协作是否正常。
- **端到端测试（E2E）**：模拟真实用户操作、走完整流程。
- **断言（Assert）**："我断定结果应为……"，不符则测试失败。

## 八、其他常见词

- **框架（Framework）**：一套规定好结构、帮你快速搭建应用的工具集合。
- **开源（Open Source）**：源代码公开、允许查看和使用的项目。
- **许可证（License）**：规定别人可以如何使用代码的法律条款。
