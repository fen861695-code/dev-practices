# dev-practices · 零基础版（Beginner Edition）

面向**零编程经验初学者**的"开发导师" Skill。它不是一份让你自己啃的规范，而是一位会**一步一步带着你做项目、并用大白话解释每条开发规则**的 AI 导师。

## 它解决什么问题

很多零基础的朋友想做一个网站或应用，却卡在：不知道从哪开始、看不懂术语、照着教程复制却不理解、做完什么也没记住。本版本让你在 AI 导师的陪伴下，**亲手把一个真实项目做出来，同时真正学会开发的知识与规则**。

## 工作方式（核心理念）

1. **一次只走一步**：讲清楚一步、等你亲手做完并确认，再进入下一步，绝不信息轰炸。
2. **大白话 + 生活类比**：所有术语先用生活事物解释（前端像餐厅大堂、后端像厨房、Git 提交像游戏存档）。
3. **代码逐行讲解**：给你的每段代码都说明每行在干嘛，让你"抄得明白"。
4. **边做边学**：每步结束小结知识点，知识与动手操作绑定。
5. **边做边记项目文档**：从第一天起维护 `PROJECT_JOURNAL.md`，最后汇总成一份完整的项目开发经验文档。
6. **鼓励式排错**：报错是学习的一部分，导师会带你逐行读懂报错、定位并解决问题。

## 引导路线（共 12 步）

0. 开始之前：认识软件开发、准备工具
1. 想清楚做什么：需求与功能清单
2. 动手前先设计：页面与数据
3. 搭建项目：安装环境、初始化
4. 学会存档：Git 入门
5. 第一个前端页面
6. 第一个后端接口
7. 前后端连起来
8. 检查自己的代码：测试入门
9. 请人把关：代码评审入门
10. 让别人能访问：发布上线
11. 回顾总结：完成项目文档

## 默认技术栈与示例项目

- 示例项目：一个**待办清单网站**（添加、查看、标记完成、删除）。
- 前端：HTML + CSS + JavaScript（先理解原理）。
- 后端：Node.js + Express。
- 数据库：SQLite（一个文件即数据库，零配置）。
- 工具：VS Code、Git / GitHub、免费托管平台。

只学一种语言（JavaScript）即可走通全栈，对初学者最友好；导师也会根据你想做的项目灵活调整。

## 快速开始

1. 让 AI 加载本目录的 `SKILL.md`（或将整个 `beginner/` 作为 Skill 安装）。
2. 直接对 AI 说："我没有任何编程基础，想从零做一个项目，请一步一步带我。"
3. 告诉导师你想做什么（或从待办清单示例开始），然后跟着每一步动手即可。
4. 第 0 步记得创建你的 `PROJECT_JOURNAL.md`，开始记录这段旅程。

## 你将获得

- 一个亲手做出并可上线运行的全栈项目。
- 对软件开发完整流程与基本规则的真实理解。
- 一份记录全过程经验、可作为作品集的项目文档。

## 与正式版的关系

仓库根目录的 `dev-practices`（SKILL.md + rules/ + checklists/）面向有经验者，是简洁、可执行的团队规范；本 `beginner/` 版本面向零基础，强调教学与陪伴。学会零基础版后，正式版就是你日常工作的速查手册。
