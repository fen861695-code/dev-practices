# 分步完成确认检查点

> 每一步结束，导师对照本清单确认小白真正完成、理解后，再进入下一步。
> 检查点刻意保持简单：能勾选、能用自己的话回答即可，不要求背诵术语。

## 第 0 步：准备工具

- [ ] 能说出前端、后端、数据库分别是做什么的（用餐厅类比即可）
- [ ] node -v、npm -v、git --version 都能显示版本号
- [ ] 知道怎么打开终端、怎么在 VS Code 里新建终端

## 第 1 步：需求

- [ ] 能用大白话说清项目做什么、给谁用
- [ ] 列出了功能清单，并区分了 MVP 和以后功能
- [ ] 已保存 REQUIREMENTS.md

## 第 2 步：设计

- [ ] 画了页面草图（输入区、列表、完成状态）
- [ ] 说出一条待办有哪些字段（id、text、done、created_at）
- [ ] 列出四个接口并对应到增删改查
- [ ] 已保存 DESIGN.md

## 第 3 步：搭建项目

- [ ] 建好目录结构，完成 npm init 和 express 安装
- [ ] server.js 能运行，浏览器访问 localhost:3000 看到那句话
- [ ] 已创建 .gitignore

## 第 4 步：Git

- [ ] 完成 git init、add、commit，git log 能看到提交
- [ ] 在 GitHub 建好仓库并 push 成功，网上能看到文件
- [ ] 能说清 add / commit / push 分别是干嘛

## 第 5 步：前端页面

- [ ] 能说出 HTML / CSS / JS 各管什么
- [ ] 页面显示标题、输入框、按钮和两条假数据
- [ ] 已配置 express.static 托管 public

## 第 6 步：后端与数据库

- [ ] 四个接口都已实现
- [ ] 用 curl 添加过待办，GET 能查到
- [ ] 重启服务器后数据仍在（持久化生效）

## 第 7 步：联调

- [ ] 网页上能添加、勾选完成、删除，页面即时更新
- [ ] 刷新页面数据仍在
- [ ] 能说清一次操作数据经过哪些环节

## 第 8 步：测试

- [ ] 抽取出纯函数并写了单元测试
- [ ] npm test 全部通过
- [ ] 见过测试"故意失败"时的红色提示

## 第 9 步：代码评审

- [ ] 建分支、推送、发起 PR，说明填写完整
- [ ] 按评审清单检查并修改了发现的问题
- [ ] PR 已合并到主线

## 第 10 步：部署上线

- [ ] 代码用环境变量适配了端口
- [ ] 在托管平台部署成功并获得公网网址
- [ ] 用公网网址验证核心功能可用

## 第 11 步：总结

- [ ] 完成 PROJECT_REPORT.md（含踩坑清单与经验总结）
- [ ] 盘点了学到的知识、确定了下一步方向
- [ ] 已提交、推送并打上 v1.0.0 标签
