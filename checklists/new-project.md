# 新项目初始化检查单

新项目启动时，按以下清单完成基础建设后再进入功能开发：

- [ ] 仓库创建，main / develop 分支保护开启，团队权限划分
- [ ] README、.gitignore、许可证、CONTRIBUTING 就位
- [ ] CI 流水线（lint、测试、构建、扫描）搭建并跑通
- [ ] 代码风格配置（Lint / Formatter / 编辑器配置）统一
- [ ] 依赖锁定（lockfile）、依赖扫描开启
- [ ] 开发 / 测试环境可一键搭建，配置模板（.env.example）就绪
- [ ] 基础目录结构按规范落地，技术选型文档（含 ADR）记录
- [ ] 日志、监控、告警通道就绪（哪怕最小集）
- [ ] 密钥管理方案确定，无密钥入库
- [ ] 测试框架与覆盖率门禁配置完成
- [ ] 文档模板（README、API、CHANGELOG）初始化
