# 安全规则（13-security）

## 基线

- 最小权限原则：账号、密钥、权限按需授予，定期回收。
- 默认安全：新代码、新接口默认启用校验与鉴权。
- 数据分类分级：识别敏感数据（个人、财务、业务机密）并分级保护。

## 依赖与供应链

- 启用依赖漏洞扫描（Dependabot 等），高危告警限期处理。
- 锁文件入库；升级走 PR 并跑全量测试。
- 生产依赖最小化；官方镜像并保持更新，镜像扫描后发布。

## 密钥与配置

- 密钥只存于密钥管理服务，禁止硬编码、入库、入日志。
- .env 不入库；提供 .env.example。
- 密钥轮换有流程；疑似泄露立即轮换并审计。

## 扫描与测试

- CI 集成 SAST 与 SCA；高风险应用补充 DAST 与人工渗透。
- 缺陷按严重程度限时修复：严重 / 高危立即处理，中危排期，低危记录。

## 数据保护

- 个人数据最小化采集、加密传输与存储、设置保留期并可删除。
- 日志与监控对敏感字段脱敏；对外响应不泄露内部信息。
- 涉及合规要求的需求上线前完成合规评审。
