# 团队协作与定义完成规则（16-collaboration）

## 任务拆分与估算

- 任务拆到可独立交付、可独立验收；单个任务建议 1-3 天内完成。
- 估算口径统一（故事点或时间），排期包含测试与缓冲。
- 任务卡片包含：描述、验收标准、依赖、负责人、优先级。

## 就绪定义（DoR）

- [ ] 需求目标、范围、优先级明确
- [ ] 验收标准可测、可验证
- [ ] 依赖（接口、数据、外部资源）已确认或明确阻塞
- [ ] 技术方案已明确，复杂需求已完成设计评审
- [ ] 已拆分为可估时任务并排期

## 完成定义（DoD）

- [ ] 代码已按规范编写并通过评审
- [ ] 单元测试、集成测试、必要的 E2E 通过
- [ ] CI 流水线全部通过，无高危安全告警
- [ ] 文档（接口、配置、使用说明）已更新
- [ ] 日志与监控已覆盖，关键路径可观测
- [ ] 发布检查单通过，回滚预案就绪
- [ ] 验收标准逐项确认通过

## 每日同步与回顾

- 站会只同步：昨天完成、今天计划、阻塞项；阻塞项 24 小时内解决或升级。
- 回顾只产出可执行改进项，每项有负责人与截止时间，下轮检查闭环。
